# The Study

Seven files, no folders. Upload all of them to the same place.

Phone-only setup with GitHub Pages:
1. Unzip this in the Files app.
2. github.com: create a free account and a new public repository named the-study.
3. In the repo: Add file > Upload files > choose all 7 files > Commit changes.
4. Settings > Pages > Source: Deploy from a branch > Branch: main, folder / (root) > Save.
5. After a minute or two the site is at https://YOUR-USERNAME.github.io/the-study/
6. Open that in Safari > Share > Add to Home Screen. Open it once while online.

Updating later: upload the new index.html to the same repo (it replaces the old one). Same address, so your library stays.
